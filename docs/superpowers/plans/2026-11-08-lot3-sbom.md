# Lot 3: SBOMs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `tabularium sbom <host> [--build]` writes the bombon CycloneDX SBOM of the host's last deployed toplevel to the store and prints its coverage.

**Architecture:** A small Nix file (`src/sbom.nix`) applies bombon's `buildBom` to the consumer's toplevel at the recorded commit (`builtins.getFlake "git+file://<repo>?rev=<commit>"`). The Bash script reads the newest record, checks it (clean, toplevel unchanged, closure present), runs `nix build --file` on that file, and copies the result with `write_new`. Store paths of `sbom.nix`, bombon and nixpkgs reach the script through `writeShellApplication`'s `runtimeEnv`.

**Tech Stack:** Bash (`writeShellApplication`), Nix flakes, bombon (non-flake entry: `import bombon { inherit pkgs; }`), jq.

**Spec:** `docs/superpowers/specs/2026-11-08-lot3-sbom-design.md`

## Global Constraints

- Output path: `$TABULARIUM_STORE/<repo>/sbom/<host>/<commit>.cdx.json`, raw bombon CycloneDX, no envelope.
- Source: newest record of `<host>` (`latest_record`): `.predicate.gitCommit`, `.predicate.dirty`, `.subject[0].name`.
- bombon is a flake input of tabularium with `inputs.nixpkgs.follows = "nixpkgs"`.
- Closure missing from the local store: refuse unless `--build`. Missing = the record's `subject` path is not valid locally (Nix invariant: a valid path has a valid closure). The toplevel is host-specific, never on a public cache, so absent ⇒ local build.
- Exit codes, existing: 1 no record / unreadable, 2 dirty, 3 file exists (race), 64 usage. New: **2** dirty record (same meaning as `record`'s), **5** evaluated toplevel ≠ record `subject`, **6** closure missing without `--build`.
- `nix flake check` stays cheap: tests use the fake `nix`; real bombon is run by hand only.
- Never assign `$out` in a test script. `errexit`/`nounset`/`pipefail` are on: guard commands that may fail.
- Docs in fish syntax, terse (tables, commands).

## Review Focus

- Recorded commit absent from the local clone (record made from a since-deleted branch): expect exit 1 and a message naming the commit, not a raw nix error. Test: `sbom_commit_missing` (Task 2).
- Record file present but unreadable/empty (as in `last_empty_record`): expect exit 1, nothing written. Test: `sbom_bad_record` (Task 2).
- Second run on the same commit: no `nix build`, same export line. Test: `sbom_reuse` (Task 2).
- `--build` given but the closure is present: same result as without it. Test: `sbom_build_flag_noop` (Task 2).
- Host name in a different case from the record directory (`rogueleader`): exit 1, "no deployment recorded". Covered by `sbom_no_record` using a lowercase name (Task 2).

- [ ] **Step 1: Write `src/sbom.nix`**

```nix
# SBOM of <host>'s toplevel at commit <rev> of the flake checked out at <repo>.
{
  repo,
  rev,
  host,
  nixpkgs,
  bombon,
}: let
  fleet = builtins.getFlake "git+file://${repo}?rev=${rev}";
  pkgs = import nixpkgs {system = builtins.currentSystem;};
in
  (import bombon {inherit pkgs;}).buildBom fleet.nixosConfigurations.${host}.config.system.build.toplevel {}
```

### Task 2: guards and cache reuse

**Files:**

- Modify: `src/tabularium.sh` (`sbom`)
- Modify: `tests/sbom.nix`

**Interfaces:**

- Consumes: `sbom`, `sbom_summary`, fake env `FAKE_NIX_TOPLEVEL`, `FAKE_NIX_MISSING`, `$TMPDIR/nix-build.log` (Task 1).
- Produces: exit codes 1, 2, 5, 6 as in Global Constraints.

Order of checks in `sbom` (each before any `nix build`):

| # | Check | Failure |
|---|---|---|
| 1 | a record exists | exit 1, `tabularium: no deployment recorded for <host>` |
| 2 | record readable (`jq -e` of commit and subject) | exit 1, `tabularium: <file> is not a valid record` |
| 3 | export file already exists | print `sbom_summary`, exit 0, no build |
| 4 | record not dirty | exit 2, `tabularium: <host> was deployed from a dirty tree, its commit does not describe it` |
| 5 | commit exists (`git cat-file -e "$commit^{commit}"`) | exit 1, `tabularium: commit <commit> is not in this clone` |
| 6 | `nix eval --raw "git+file://$PWD?rev=$commit#nixosConfigurations.$host.config.system.build.toplevel.outPath"` equals `subject` | exit 5, `tabularium: <host> at <commit> evaluates to <path>, the record says <subject>` |
| 7 | `nix path-info --json --json-format 2 "$subject"` succeeds, or `--build` | exit 6, `tabularium: <subject> is not in the local store; rerun with --build to build it` |

Reuse (3) comes before dirty (4) on purpose: a file can only exist for a clean record.
